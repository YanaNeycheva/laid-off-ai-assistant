05

Risky-action radar

bandtool hook

Flags commands that delete data, rewrite git history, or write outside the project, and pauses them until you decide. You don't have to read every command to catch the dangerous ones.

I'll remove the generated output folders.

⚠ Paused: deletes outside the project and the git-ignored Personal/ folder (person data, no backup)
Ask Claude anything…
opus-5.5radar: 1 paused
Data: on('tool.call', {tool:'Bash'}) matches patterns (rm -rf, push --force, reset --hard, paths outside cwd) and returns { deny } until you allow it.
